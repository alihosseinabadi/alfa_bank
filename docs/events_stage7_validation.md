## Границы выводов

Visibility ack — недоверенный клиентский сигнал, а не независимое доказательство
чтения. material_open не является qualified use. server_verified у тестового
платежа означает только доверенный тестовый путь; это не реальная оплата.
Actor/payment principals передаёт будущий доверенный серверный адаптер;
сам DTO не реализует auth или проверку подписи провайдера.

Составная actor/item/impression связь проверена сервисом. При прямом обходном
INSERT отдельные FK не обеспечивают всю составную согласованность.
MVP использует один writer через EventService.

Снимки и query hash остаются приватными, хэш не является полной анонимизацией.
Качество поиска из docs/quality_stage56.md этим этапом не исправлялось.
Reward ledger, атрибуция, maturity, профильная проекция и LinUCB ещё не реализованы.
Онлайн-конверсия, награды и бизнес-эффект не измерялись.
