# Этап 5 MVP: состояние на 13 ноября 2026 года

Этап 5 — контентный поиск TF-IDF + косинусное сходство по реальному каталогу:
до 50 уникальных материалов под текущую задачу или интересы из RequestContext.
Этап частично реализован; окончательная оценка качества ещё не завершена.

## Уже выполнено

- Добавлены чистые ML-контракты, TF-IDF по русским словам и биграммам,
  нормализация регистра, ё/е и обозначения 1С.
- Публичные фрагменты объединяются до материала по максимальному score.
  Повторный текст удаляется до обучения IDF; порядок результатов детерминирован.
- Реализованы ограничения формата, бесплатного доступа и известной длительности.
  Неизвестная цена/длительность и неподтверждённая доступность URL отмечаются явно.
- Явная задача имеет приоритет над историей. Пустой запрос, слабое совпадение
  и отсутствие допустимых материалов дают уточнение без выдуманной релевантности.
- Результат содержит публичное свидетельство, источник, причину и переход
  по URL материала. Продолжение обучения передаётся отдельно с требованием проверки прав.
- Добавлены тематический baseline, расчёт метрик и скрипт оценки.
- Реализованы сохранение без pickle, контрольные суммы, совместимость версий,
  атомарная публикация и полная реконструкция индекса из каталога.
- Реальный индекс: 1444 материала, 9965 уникальных публичных фрагментов из 9982.
  Закрытые фрагменты и платные тексты уроков не включены.
- Проверены каталог, история и 7420 профилей предыдущих этапов.
  Прошли 118 тестов; две повторные сборки дали одинаковый ID индекса.
- Независимый агент заранее зафиксировал 20 искусственных сценариев
  (10 development / 10 test) и 39 начальных ручных оценок.
  Подготовлен слепой пул материалов двух методов. Данные и индексы остаются вне Git.

## Как запустить

Из корня репозитория в окружении conda alpha:

```bash
python scripts/build_retrieval_index.py
python scripts/build_retrieval_index.py --verify
python scripts/search_materials.py --task "Рассчитать НДС" --formats calculator --free-only --k 6
python -m pytest backend/tests -q
```

Оценка выполняется через scripts/evaluate_retrieval.py после завершения
локального pool_judgments.json. Не запускать --collect-only повторно поверх
зафиксированного benchmark без явного решения создать новую версию оценки.
