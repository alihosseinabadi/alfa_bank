# Подготовка данных для рекомендательной системы

Используем предоставленный организаторами PostgreSQL backup.

Исходные данные и производные выгрузки хранятся локально:
- data/raw — исходные файлы
- data/interim — промежуточные таблицы
- data/processed — подготовленные материалы и взаимодействия
- reports — локальные отчёты о качестве

Эти папки исключены из Git.

Демонстрационный data/courses/courses.csv остаётся синтетическим
примером и не заменяет настоящий каталог.

Порядок реализации:
1. Проверить структуру, количество записей и связи.
2. Выгрузить необходимые таблицы.
3. Собрать общий каталог материалов.
4. Очистить тексты, темы, теги и характеристики.
5. Нормализовать историю пользователей.
6. Проверить пропуски, дубликаты и противоречия дат.
7. Подготовить данные для TF-IDF и оценки рекомендаций.

Код доступа к источнику и подготовки данных:
backend/app/data_preparation/

ML-алгоритмы:
backend/app/ml/

CLI-команды:
scripts/

Проверка исходной базы:
scripts/sql/check_source_db.sql

Исторические привязки и прохождение не считаются показами
или кликами. Отсутствие взаимодействия не считается отказом.

## Очистка и предварительный отбор

Полный каталог сохраняется без удаления записей.
Отдельная подборка для общей ленты исключает удалённые,
неопубликованные и закрытые материалы, записи без названия
или ссылки. Для статей дополнительно требуется IsPublic=true.

Платные материалы и подписка допускаются с переходом
на страницу материала. Фильтр не проверяет фактическую
доступность страницы или права конкретного пользователя.

Отсутствие цены или длительности сохраняется как пропуск.
Бесплатность определяется типом доступа, а не пустой ценой.
Скрипты и стили исключаются из очищенного текста.
Удалённые темы, теги и отраслевые метки не используются.

Запуск: python scripts/clean_material_catalog.py
