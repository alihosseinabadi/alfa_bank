# Этап 5 Гибридный поиск Состояние работ

Этап ещё не принят. В дополнение к восстановленному TF-IDF реализуются экспериментальные BM25, E5 и объединение результатов reciprocal rank fusion. Для E5 используется локальная модель intfloat/multilingual-e5-base с ревизией d128750597153bb5987e10b1c3493a34e5a4502a. Контрольная сумма весов a18a44fad1d0b46ded15928144138cff1135d5cc8233bdd90be5f18822de09a7 совпала с манифестом поставщика. Данные организаторов не отправлялись наружу.

Каталог и зафиксированный пул предыдущей предварительной оценки скопированы на D. Проверка копии TF-IDF индекса подтвердила 1444 индексируемых материала и 9965 уникальных публичных фрагментов; защищённых и платных тел в индексе не обнаружено. Исходные данные, векторы, модели и разметка исключены из Git.

Модуль BM25 использует общий публичный корпус и ограничения доступа; E5 вычисляет векторы локально, усредняет маскированные токены и нормирует результат. Каналы объединяются по рангам. Гибридный поиск требует явно заданного порога семантического сходства: порог не откалиброван и не является гарантией релевантности. Код и интерфейс носят экспериментальный характер, не подключены к пользовательскому API.

Построение E5-векторов завершено в двух сегментах и объединено. Первая часть дополнительно проверена повторным расчётом 32 равномерно выбранных векторов; это выборочная проверка, не полная реконструкция. Частичный файл не является готовым индексом; счётчик содержится в checkpoint.json. До завершения нельзя использовать эти данные для поисковой выдачи. Первая часть создана до усиления записи информации о версиях; контрольную точку следует сохранить для аудита. Подготовлен verify_e5_prefix.py для повторной проверки восьми граничных векторов. Вторая часть записывает версии и может быть продолжена только при совпадении параметров. Готовый индекс необходимо проверить по идентификатору исходного индекса, хешам модели и матрицы, числу векторов, их размерности и норме.

Добавлены автоматические проверки доступа, детерминизма, повторной индексации BM25, качества входных данных, совместимости версии контекста, объединения рангов и отказа от перезаписи benchmark. Последний полный прогон исходных тестов с добавленными к тому моменту проверками: 126 passed. Более новые тесты новых модулей запускались отдельно; требуется финальный повторный полный прогон.

Проведено исследовательское сравнение пяти методов; подробности, результаты и ограничения приведены в docs/retrieval_stage5_report_2026_11_14.md. Старые тестовые сценарии уже просматривались при предыдущей разметке, поэтому повторное использование не создаёт независимый закрытый тест. Параметры фиксируются до сбора результатов; не подбирать порог по тестовой части. Требуется новая слепая разметка по публичным свидетельствам, независимое ревью, анализ потерь, честная оценка по критериям хакатона и выпуск отчёта. Веса модели и зависимые пакеты не доказывают качество рекомендаций и роста конверсии.
