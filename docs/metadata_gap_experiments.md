# Эксперименты с порогом подборки и метаданными

Дата: 2026-11-16. База: lead 01aa4ba. Эксперименты исследовательские; действующие политики и их версии не менялись.

## Совпадение названия и темы

На 59 development-сценариях синтетического benchmark light_benchmark_v1 сравнивался light-hybrid-search-v2 с дополнительной оценкой доли нормализованных слов запроса в названии и в темах. Все сравнения на одних кандидатах. Пары весов: (0, 0), (0.01, 0.005), (0.025, 0.01), (0.05, 0.02). NDCG@10: 0.62233, 0.62047, 0.61891, 0.61704; Success@5: 0.84746 во всех случаях. Это синтетический набор с разметкой, полученной при построении; один набор не позволяет обобщить вывод на реальные запросы. Проверенные варианты не улучшили dev: бонус не включён. Holdout для настройки не использовался.

Запуск: OPENBLAS_NUM_THREADS=2 python scripts/experiment_metadata_dev.py. Скрипт требует light-hybrid-search-v2 и синтетический benchmark из ветки lead, коммит 01aa4ba; в ветке ml эти зависимости отсутствуют. Для воспроизведения запускайте его в рабочей копии lead после переноса скрипта.

## Порог relevance_gap

На локальном реальном каталоге использовались TF-IDF, приоритетное ранжирование и пустая модель shared LinUCB. Прогон семи доступных размеченных dev-задач по 10 seed сравнивает gap=0.15, 0.4, 0.5, 0.6, 0.7. Локальные сценарии и оценки остаются вне Git.

| gap | средний размер | размечено показов | доля grade >= 2 среди размеченных | хотя бы один размеченный полезный |
|---|---:|---:|---:|---:|
| 0.15 | 1.00 | 100% | 100% | 7/7 |
| 0.40 | 1.43 | 100% | 90% | 7/7 |
| 0.50 | 1.71 | 100% | 83.3% | 7/7 |
| 0.60 | 2.57 | 100% | 55.6% | 7/7 |
| 0.70 | 3.57 | 100% | 44% | 7/7 |

Десять seed описывают случайность политики, а не десятикратное увеличение независимых запросов. Для 0.4 добавились три карточки на семь задач, две из них получили grade >= 2; это компромисс, а не доказательство общего улучшения. Гибрид v2 и обученная модель не проверялись. Старый набор уже раскрыт, так что он не является независимой контрольной выборкой.

Запуск: OPENBLAS_NUM_THREADS=2 python scripts/experiment_slate_gap_dev.py. Требуются приватные локальные data/interim/quality_stage56 и каталог с индексом; оценки не перезаписываются.

## Независимое ревью

Критик воспроизвёл оба скрипта и подтвердил числа. Рекомендация: не менять значение по умолчанию и исторические версии, gap=0.4 использовать только как явно передаваемый экспериментальный параметр relevance_gap; перед включением выбрать решение по новым отдельно размеченным запросам. Бонусы оставить выключенными.

Запросы вне каталога, реальные конверсии, пользовательский API и E5 этим экспериментом не оценивались.
